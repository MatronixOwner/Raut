RAUT 1.0.0 — КРАТКАЯ ИНСТРУКЦИЯ
================================

ЧТО ЭТО
  Raut — голосовой чат, демонстрация экрана, друзья и личные сообщения.
  Аккаунты, список друзей и история хранятся на сервере проекта (или на
  вашем локальном сервере, если общий ещё не подключён). Настраивать
  сервер пользователю НЕ нужно: зарегистрировались, добавили друга по
  логину — и общаетесь. Внешних зарубежных сервисов нет.

ПЕРВЫЙ ЗАПУСК
  Ярлык «Raut» в меню «Пуск» (или на рабочем столе) запускает bin\node.exe
  напрямую с параметром --open: поднимается локальный сервер на порту 8787
  и открывается приложение в отдельном окне Microsoft Edge / Google Chrome
  без адресной строки. Если сборка указывает RAUT_PUBLIC_URL, откроется
  сразу общий сервер Raut.

  На экране входа нажмите «Регистрация», придумайте логин и пароль (от 6
  символов). Токен сессии сохранится — при следующем запуске вход будет
  автоматическим. Затем «Добавить друга» → введите его логин → он принимает
  запрос → личный чат, голос и демонстрация экрана. Можно зайти и как гость,
  но тогда друзья и личные сообщения недоступны.

  Запуск НЕ использует VBS/WSH, скрытые окна и автозагрузку: ярлык
  указывает на node.exe, а окно браузера открывает сам сервер через
  child_process.spawn (см. BUILDINFO.txt).

  Требования: Windows 10/11 (x64) и установленный Microsoft Edge
  (есть во всех современных Windows) либо Google Chrome.
  Права администратора не нужны.

КАК ПОЗВАТЬ ДРУГИХ
  * Локальная сеть: ярлык «Сервер Raut» открывает консоль, где сервер
    печатает LAN-адреса вида http://192.168.1.42:8787/. Друзья открывают
    этот адрес в браузере (или вводят его на экране входа в Raut).
    Те же адреса видны в «Настройки → Сеть и сервер».
  * Общий сервер: администратор один раз разворачивает Raut на VPS с
    доменом и HTTPS (готовый комплект — deploy/ в репозитории). Пользователи
    просто заходят на этот адрес и регистрируются. STUN/TURN задаются на
    сервере переменными RAUT_STUN / RAUT_TURN_URL / RAUT_TURN_USER /
    RAUT_TURN_PASS — пользователям настраивать ничего не нужно.
    Без HTTPS браузер не даст доступ к микрофону и захвату экрана.

КАЧЕСТВО
  Звук: WebRTC / Opus 48 кГц, стерео, 64–510 кбит/с (по умолчанию 256),
  FEC, настраиваемые эхоподавление и шумоподавление, выбор микрофона
  и динамиков, громкость каждого собеседника.
  Экран: до 3840×2160 / 60 FPS / 30 Мбит/с, отдельные WebRTC-соединения,
  поэтому голос не прерывается при старте трансляции, системный звук.
  Всё шифруется DTLS-SRTP; сервер видит только сигналинг и текст чата.

ГДЕ ЛЕЖАТ ДАННЫЕ
  %LOCALAPPDATA%\Raut\app\data  — state.json: аккаунты, токены, друзья,
                                  личные сообщения, история и вложения
  %LOCALAPPDATA%\Raut\profile   — профиль окна приложения
  Если сборка указывает общий сервер (RAUT_PUBLIC_URL), аккаунты и чаты
  хранятся ТАМ; локальная папка остаётся офлайн-копией.

  Экран входа: «Регистрация» → логин и пароль → «Добавить друга» → логин
  друга. Меню сервера → «Во что играю» — статус увидят друзья.
  Настройки клиента — в localStorage этого профиля.

УДАЛЕНИЕ
  «Пуск → Raut → Удалить Raut» или «Параметры → Приложения».
  При удалении можно сохранить историю сообщений в %APPDATA%\Raut\data.

ЕСЛИ АНТИВИРУС ПИШЕТ «ОБНАРУЖЕН ВИРУС»
  Это почти наверняка ложное срабатывание: установщик не подписан
  (нет сертификата Code Signing), упакован NSIS/LZMA и содержит внутри
  настоящий node.exe — эвристики некоторых антивирусов считают это «пакером».
  Что делать:
    1. Сверьте SHA-256 установщика с файлом .sha256 (PowerShell):
         Get-FileHash .\RautSetup-1.0.0.exe -Algorithm SHA256
       и SHA-256 bin\node.exe с BUILDINFO.txt.
    2. Проверьте файл на https://www.virustotal.com/gui/home/upload
    3. Если Defender заблокировал: «Безопасность Windows → Защита от вирусов
       и угроз → Журнал защиты → Разрешить на устройстве».
    4. Альтернатива без инсталлятора: Raut-1.0.0-portable.zip — распакуйте
       и запустите Run-Raut.cmd.
    5. Полная проверка: соберите установщик из исходников сами —
       `bash scripts/build-installer.sh` (см. README.md).

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  * Проверьте, не занят ли порт 8787: `netstat -ano | findstr 8787`.
  * Логи сервера: запустите из этой папки в командной строке
    `bin\node.exe app\server\index.js --client app\client --data app\data --port 8787 --open`
