RAUT — ГОЛОС, ВИДЕО И СЕРВЕРЫ ДЛЯ СВОИХ
======================================

Raut — открытый мессенджер, который работает на вашем компьютере:
серверы, текстовые и голосовые каналы, личные звонки, демонстрация экрана.
Переписка шифруется прямо на устройстве, а микрофон проходит через
нейросеть-шумодав — вас слышно чисто даже с дешёвой гарнитурой.


КАК ЗАПУСТИТЬ
-------------
Двойной щелчок по Raut.exe. Больше ничего настраивать не нужно:
сервер поднимется сам, окно приложения откроется автоматически.

При первом запуске зарегистрируйтесь (имя, пароль — и всё).


КАК ПОЗВАТЬ ДРУЗЕЙ
------------------
Вариант 1 — по сети (вы в одной Wi-Fi/локальной сети):
  В приложении откройте сервер → блок «Приглашение» → скопируйте код.
  Друзья запускают Raut у себя, выбирают «Войти по приглашению»,
  вставляют код — и они в вашем сервере.

Вариант 2 — через интернет:
  Нужен сервер, доступный снаружи (VPS, или проброс порта 8787).
  В приложении: Настройки → Сервер → введите адрес, например
  https://raut.example.com или http://31.13.х.х:8787


ГОРЯЧИЕ КЛАВИШИ
---------------
  Ctrl+K            командная палитра (перейти куда угодно)
  Enter             отправить, Shift+Enter — перенос строки
  Ctrl+Shift+M      микрофон вкл/выкл
  Ctrl+Shift+D      звук вкл/выкл


ЧТО ГДЕ ЛЕЖИТ
-------------
  Raut.exe            приложение (сам сервер внутри — Node.js для Windows)
  Raut-console.cmd    запуск из командной строки и остановка (--stop)
  app\                сервер и веб-клиент
  data\               переписка, файлы, ключи (появляется после запуска)
  data\server.log     журнал сервера — сюда смотреть, если что-то не так
  Uninstall.exe       удаление

Из командной строки (cmd или PowerShell):
  "%LOCALAPPDATA%\Raut\Raut-console.cmd" --stop
  "%LOCALAPPDATA%\Raut\Raut-console.cmd" --port 8788


ШИФРОВАНИЕ
----------
Сообщения и файлы шифруются на устройстве отправителя (AES-256-GCM),
ключи каналов передаются только участникам (ECDH P-256). Сервер хранит
шифротекст и не может прочитать переписку.

Ключи вашего устройства живут в профиле браузера/приложения. Если
очистить данные приложения — старые сообщения расшифровать не получится.
Это цена настоящего сквозного шифрования.


ГОЛОС И ВИДЕО
-------------
Звонки идут напрямую между компьютерами (WebRTC, Opus 48 кГц,
DTLS-SRTP). Для соединения через интернет нужен доступный STUN/TURN —
по умолчанию используется STUN Google. В локальной сети звонки
работают сразу.

Совет: наденьте наушники — без них включается эхоподавление и голос
звучит «телефонно». Шумодав (GTCRN) включён по умолчанию.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• Антивирус ругается на неподписанный установщик — это обычная реакция
  SmartScreen на любые NSIS-сборки без платного сертификата. Проверьте
  SHA-256 из файла .sha256 рядом с установщиком.
• Порт 8787 занят — Raut подберёт свободный или возьмите портативную
  версию и запустите Raut.exe --port 8788.
• Микрофон не работает — Windows → Параметры → Конфиденциальность →
  Микрофон → разрешить приложениям.
• Нужно остановить сервер — «Остановить Raut» в меню «Пуск» или
  Raut-console.cmd --stop.
• Голос подключился, но микрофона нет — Raut работает в режиме слушателя;
  нажмите кнопку микрофона, чтобы попробовать подключить устройство снова.
