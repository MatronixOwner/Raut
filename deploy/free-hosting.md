# Бесплатные площадки для общего сервера Raut

Цель: одна публичная ссылка, по которой вы и друг заходите, регистрируетесь,
добавляете друг друга и играете. **Если нужен именно голос + текст, а не только чат —
сразу читайте [voice-hosting.md](voice-hosting.md)**: бесплатные PaaS не дают UDP,
поэтому там голос между разными сетями не работает. Ниже — что реально бесплатно в 2026 году,
с честными ограничениями. Условия проверены 04.11.2026.

## Техническое ограничение, которое важно именно для Raut

Raut хранит аккаунты, друзей и историю в `data/state.json`, а голос и экран идут
через WebRTC. Поэтому площадка должна уметь три вещи:

1. **Постоянный диск** — иначе аккаунты и друзья исчезнут при перезапуске.
2. **Долгий WebSocket** — без него «соединение потеряно».
3. **UDP-порт для собственного STUN/TURN** — без него голос между двумя
   разными домашними сетями может не соединиться. На бесплатных PaaS обычно
   открыт только HTTPS, UDP нет. Полный функционал даёт только VPS.

Чат, регистрация, друзья, ЛС и шаринг экрана в одной сети работают и без UDP.
Для голоса через интернет берите VPS.

## Рекомендация №1 — тестовый VPS в России (лучший вариант)

| Провайдер | Бесплатно | Карта | Что даёт |
| --- | --- | --- | --- |
| **Beget** | до 30 дней | не нужна на старте | VPS, NVMe, бесплатный SSL, поддержка 24/7 |
| **SpaceWeb (sweb.ru)** | 3–14 дней, есть акция «1-й месяц 0 ₽» | не нужна, подтверждение по телефону | VPS с Docker и Node.js, бесплатный домен |
| **Timeweb** | 10 дней | не нужна на старте | VPS + до 3 бесплатных доменов .RU/.РФ |
| **SmartApe** | 14 дней | не нужна | VPS |
| **Selectel** | бонус на 1–3 месяца | уточняйте | облачный сервер |

Плюс: российский IP, нормальная доступность из РФ, открыты все порты, свой TURN,
данные остаются на диске. Минус: тест конечен, дальше ~200–900 ₽/мес.
Для «проиграть с другом» месяца более чем достаточно.

**Одна команда, домен покупать не надо:**

```bash
sudo bash deploy/one-shot.sh
# скрипт сам определит публичный IP и возьмёт бесплатный HTTPS-адрес
# вида https://raut.1-2-3-4.sslip.io с сертификатом Let's Encrypt
```

Если есть свой домен: `sudo bash deploy/one-shot.sh chat.example.ru`.
Если передать `GH_TOKEN` (`GH_TOKEN=... sudo -E bash one-shot.sh`), скрипт сам
запишет адрес в `SERVER_URL.txt` — и все уже установленные копии Raut переедут
на общий сервер без переустановки.

Источники: [hostinghub.ru](https://hostinghub.ru/top/vds/free),
[vc.ru — тестовые периоды](https://vc.ru/rating_top/2916800-luchshie-vps-vds-provaideri-s-testovym-periodom),
[sweb.ru — бесплатный VDS](https://sweb.ru/vds/free/).

## Рекомендация №2 — Northflank Sandbox (бесплатно всегда, не засыпает)

**Пошаговая инструкция: [northflank.md](northflank.md).**

Два сервиса, одна БД, always-on без cold start, WebSocket, HTTPS-поддомен,
постоянные тома. Карта нужна только для верификации (российская может не пройти).
UDP для TURN всё равно нет.

New Project → Service → из этого репозитория, `Dockerfile`, порт из `$PORT`,
том на `/app/data`. Источник: [Northflank](https://northflank.com/blog/best-persistent-sandbox-platforms),
[сравнение бесплатных Node-хостингов](https://hostgage.com/best-free-nodejs-hosting/).

## Рекомендация №3 — Render Free (бесплатно навсегда, без карты)

750 ч/мес, 512 МБ, HTTPS-поддомен `*.onrender.com`, WebSocket. **Но**: засыпает
через 15 минут простоя (просыпается ~минуту) и **не имеет постоянного диска** —
аккаунты сбрасываются при каждом засыпании. Хорошо «на один вечер поиграть»,
плохо как постоянный сервер. По разным источникам вопрос с WebSocket на free
освещается противоречиво — проверяется фактом деплоя.

Готовый [`render.yaml`](../render.yaml) в корне: Dashboard → New → Blueprint →
выбрать репозиторий → Deploy. Источники: [Render free tier](https://justinmckelvey.com/blog/is-render-free),
[Render Free vs Starter](https://actualdatabase.com/render-free-vs-starter-pricing/).

## Рекомендация №4 — Railway (почти бесплатно, с постоянным диском)

$5 кредита на 30 дней без карты, дальше $1/мес навсегда; 0.5 ГБ постоянного
Volume, HTTPS `*.up.railway.app`, WebSocket. Кредита хватает на маленький
неспешный сервис, но не на 24/7 под нагрузкой. UDP для TURN нет.

Готовый [`railway.toml`](../railway.toml): New Project → Deploy from GitHub repo →
добавить Volume на `/app/data`. Источник: [Railway Free Trial](https://docs.railway.com/pricing/free-trial),
[Railway pricing 2026](https://temps.sh/blog/railway-pricing-2026).

## Что НЕ стоит брать

- **Fly.io** — бесплатного тарифа нет с октября 2024, только trial на 2 часа / 7 дней: [pricing 2026](https://temps.sh/blog/fly-io-pricing-2026).
- **Oracle Cloud Always Free** — технически лучший вариант (4 ARM-ядра, 24 ГБ, навсегда), но из России регистрация практически недоступна: отклоняет карты РФ, подтверждение платёжного метода обязательно [разбор](https://grinny.io/kak-oplatit/oracle), [пример отказа](https://github.com/transformation161-droid/warehouse/pull/5).
- **Koyeb** — карта с холдом $29 и засыпание через час.
- **Vercel / Netlify / GitHub Pages** — только статика, WebSocket и Node-процесс недоступны.

## Домен и HTTPS бесплатно

- **`sslip.io` / `nip.io`** — имя вида `raut.1-2-3-4.sslip.io` само резолвится в IP,
  регистрировать нечего; Caddy получает сертификат Let's Encrypt по HTTP-01.
  Уже встроено в `one-shot.sh`: [разбор](https://escribano.dev/en/blog/007-sslip-io-homelab-dns/).
- **DuckDNS** — бесплатный поддомен + DNS-01: [инструкция](https://indiependente.dev/posts/2024/09/free-ssl-certificates-for-your-homelab-with-duckdns-and-dns-01/).
- **Timeweb** даёт до 3 доменов .RU/.РФ при регистрации — российский вариант без зарубежного DNS.
- PaaS (Render/Railway/Northflank) выдают готовый HTTPS-поддомен сами, домен вообще не нужен.

## Что делает агент после выбора площадки

1. Выполняет одну команду (`one-shot.sh` на VPS или Deploy Blueprint на PaaS).
2. Проверяет `/api/health`, HTTPS, WSS, регистрацию двух пользователей и дружбу.
3. Вписывает адрес в `SERVER_URL.txt` → все установленные копии Raut переезжают сами.
4. Отдаёт одну ссылку для вас и друга. Пользователь ничего не настраивает.
